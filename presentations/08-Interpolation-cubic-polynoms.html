Кусочно-многочленная интерполяция

Пусть f ∈ C(r)([a, b]). Можем построить приближающий многочлен степени kn или сделать кусочно-многочленное приближение k многочленами степени n.

По Теореме Джексона для апроксимации многочленом Pf степени n − 1:

$$ ||f-Pf||_C \le const(r)(\frac{b-a}{n-1})^r \omega (f^{(r)}; \frac{b-a}{2(n-1-r)}), где\\ \omega(g,h)=sup\{|g(x)-g(y)|: x, y \in [a,b], |x-y|\le h\} $$ - модуль непрерывности функции g

Разбиение отрезка [a, b] на k частей по сравнению с увеличением степени многочлена степени kn:

  1. Требуется решать k систем размера n вместо одной размера kn.
  2. С ростом степени многочлена растёт обусловленность базиса. Разбиение отрезка на части не влечёт её увеличения.

Кусочно-линейная интерполяция

Пусть заданы точки a = x1 < x2 < ... < xn = b и значения f(xi) в этих точках.

На каждом отрезке [xi, xi + 1] I2f - линейная функция.

По интерполяционной формуле Ньютона для всех x ∈ [xi, xi + 1]:

$$ \begin{equation} I_2f(x) = f(x_i) + (x-x_i)f(x_i;x_{i+1}) = f(x_i) + (x-x_i)\frac{f(x_{i+1})-f(x_i)}{x_{i+1}-x_i} \end{equation} $$ $$ \begin{equation} ||f-I_2f||_{C([a,b])} \le \frac{1}{8}h^2||f''||_{C([a,b])}, где\\ h=\max_{i=1,2,\dots,n-1}(x_{i+1}-x_i) \end{equation} $$

Кусочно-кубическая интерполяция

Пусть заданы точки a = x1 < x2 < ... < xn = b и значения f(xi) в этих точках.

На каждом отрезке [xi, xi + 1] Pf - многочлен 3 степени:

$$ \begin{equation} \begin{cases} P_i(x_i) = f(x_i),& P_i(x_{i+1}) = f(x_{i+1}), \\ P'_i(x_i) = d_i,& P'_{i+1}(x_{i+1}) = d_{i+1} \\ \end{cases} \end{equation} $$

di - свободные параметры, выбор которых определяется конкретным методом

Общая схема

Pi(x) = a1, i + a2, i(x − xi) + a3, i(x − xi)2 + a4, i(x − xi)2(x − xi + 1)

$$ \begin{equation} \begin{cases} a_{1,i} = f(x_i) \\ a_{2,i} = d_i \\ a_{3,i} = \frac{f(x_i;x_{i+1}) - d_i}{x_{i+1} - x_i} \\ a_{4,i} = \frac{d_i + d_{i+1} - 2f(x_i;x_{i+1})}{(x_{i+1} - x_i)^2} \\ \end{cases} \end{equation} $$

$f(x_i;x_{i+1})=\frac{f(x_{i+1})-f(x_i)}{x_{i+1}-x_i}$ - разделенная разность

Общая схема

Pi(x) = c1, i + c2, i(x − xi) + c3, i(x − xi)2 + c4, i(x − xi)3

$$ \begin{equation} \begin{cases} c_{1,i} = a_{1,i} = f(x_i) \\ c_{2,i} = a_{2,i} = d_i \\ c_{3,i} = a_{3,i} - a_{4,i}(x_{i+1}-x_i) = \frac{3f(x_i;x_{i+1})-2d_i-d_{i+1}}{x_{i+1}-x_i} \\ c_{4,i} = a_{4,i} = \frac{d_i + d_{i+1} - 2f(x_i;x_{i+1})}{(x_{i+1} - x_i)^2} \\ \end{cases} \end{equation} $$

Кусочная интерполяция кубическими многочленами Эрмита

Известны значения f(x) и f′(x) в точках xi, i = 1, .., n

di = f ′(xi)

Свойства:

  1. $$||f-Pf||_{C([a,b])}\le \frac{1}{4!}\frac{1}{2^4}h^4||f^{(4)}||_{C([a,b])}$$, где h = maxi(xi + 1 − xi)
  2. Значения Pf зависят только от значений f и f ′ в точках xi и xi + 1
  3. Pf линейно. P(f + g) = Pf + Pg, P(αf) = αPf

Кусочная интерполяция кубическими многочленами Бесселя

Известны значения f(x) в точках xi, i = 1, .., n

P(i)(x) = f(xi − 1) + (x − xi − 1)f(xi − 1; xi) + (x − xi − 1)(x − xi)f(xi − 1; xi; xi + 1)

$$d_i = P'_{(i)}(x_i) = \frac{(x_{i+1}-x_i)f(x_{i-1};x_i) + (x_i-x_{i-1})f(x_i;x_{i+1})}{x_{i+1}-x_{i-1}}$$, где i = 2, 3, ..., n − 1

В случае равномерного распределения точек xi: $d_i=\frac{f(x_{i+1})-f(x_{i-1})}{2h}$, где i = 2, 3, ..., n − 1

Недостающие значения d1 и dn определяются отдельно.

Кусочная интерполяция кубическими многочленами Бесселя

Свойства:

  1. ||f − Pf||C([x2, xn − 1]) ≤ const ⋅ h3||f||C(3)([a, b])
  2. Значения Pf зависят только от значений f в точках xi − 1, xi, xi + 1, xi + 2
  3. Pf линейно. P(f + g) = Pf + Pg, P(αf) = αPf

Кусочная интерполяция кубическими многочленами Акимы

Известны значения f(x) в точках xi, i = 1, .., n. Метод используется для борьбы с выбросами из-за погрешности значений функции.

$$ d_i = \begin{cases} \frac{w_{i+1}f(x_{i-1};x_i)+w_{i-1}f(x_i;x_{i+1})}{w_{i+1}+w_{i-1}}, & если\ w^2_{i+1}+w^2_{i-1} \ne 0 \\ \frac{(x_{i+1}-x_i)f(x_{i-1};x_i) + (x_i - x_{i-1})f(x_i;x_{i+1})}{x_{i+1}-x_{i-1}}, & если\ w_{i+1}=w_{i-1}=0 \end{cases} \\ , где\ i=3, 4, ..., n-2 \\ w_j = |f(x_j;x_{j+1})-f(x_{j-1};x_j)| $$

Недостающие значения d1, d2, dn − 1 и dn определяются отдельно.

Кусочная интерполяция кубическими многочленами Акимы

Свойства:

  1. ||f − Pf||C([x3, xn − 2]) ≤ const ⋅ h2||f||C(2)([a, b])
  2. Значения Pf зависят только от значений f в точках xi − 2, xi − 1, xi, xi + 1, xi + 2, xi + 3
  3. Pf не линейно. P(f + g) ≠ Pf + Pg , хотя P(αf) = αPf

Кусочная интерполяция кубическими многочленами с использованием разделённых разностей

Известны значения f(x) в точках xi, i = 1, .., n. Небольшие требования к гладкости функции, можно использовать для снижения влияния погрешности значений f(xi).

$$ d_i = \begin{cases} sign\ f(x_i;x_{i+1})\cdot min\{|f(x_{i-1};x_i)|, |f(x_i; x_{i+1})|\}, & если\ sign\ f(x_{i-1};x_i) = sign\ f(x_i;x_{i+1}) \\ 0 & иначе \end{cases} \\, где\ i=2, 3, ..., n-1 \\ $$

Недостающие значения d1 и dn определяются отдельно.

Кусочная интерполяция кубическими многочленами с использованием разделённых разностей

Свойства:

  1. ||f − Pf||C([x2, xn − 1]) ≤ const ⋅ h2||f||C(2)([a, b])
  2. Значения Pf зависят только от значений f в точках xi − 1, xi, xi + 1, xi + 2
  3. Pf не линейно. P(f + g) ≠ Pf + Pg, хотя P(αf) = αPf

Определение недостающих граничных условий

  1. По известным значениям первой производной функции в граничных узлах
  2. По известным значениям второй производной функции в граничных узлах
  3. "Естественные граничные условия"
  4. Условие "отсутствия узла" в приграничных узлах
  5. Дополнительный узел в приграничных узлах
  6. Экстраполяция в приграничных узлах

По первой производной

d1 = f ′(x1), dn = f ′(xn)

Для метода Акимы дополнительно: d2 = f ′(x2), dn − 1 = f ′(xn − 1)

По второй производной

$$\begin{cases} 2d_1 + d_2 = 3f(x_1;x_2) - \frac{1}{2}f''(x_1)(x_2-x_1) \\ d_{n-1} + 2d_n = 3f(x_{n-1};x_n) + \frac{1}{2}f''(x_n)(x_n-x_{n-1})\\ \end{cases}$$

В методе Акимы d1 и dn определяются по первой производной. В остальных методах эти параметры известны.

Естественные граничные условия

Этот метод используется, когда нет никакой дополнительной информации о приближаемой функции f.

(Pf)″(x1) = 0, (Pf)″(xn) = 0

При f ″(x1) = 0 и f ″(xn) = 0 получаем $$ \begin{cases} 2d_1+d_2 = 3f(x_1;x_2) \\ d_{n-1}+2d_n = 3f(x_{n-1};x_n)\\ \end{cases} $$

В остальных случаях повышенная погрешность в граничных узлах.

Отсутствие узла в приграничных узлах

Этот метод используется, когда нет никакой дополнительной информации о приближаемой функции f.

Считаем, что P1 ≡ P2, Pn − 2 ≡ Pn − 1.

В этом случае P1 интерполирует f на отрезке [x1, x3] по точкам x1, x2, x3. Pn − 1 - на отрезке [xn − 2, xn] по точкам xn − 2, xn − 1, xn.

Тогда P ′1(x3) = d3, P ′n − 1(xn − 2) = dn − 2

P1 ≡ P2 и Pn − 2 ≡ Pn − 1 строятся как интерполяционные многочлены 3й степени с кратным узлом.

Дополнительный узел в приграничных узлах

Этот метод используется, когда нет никакой дополнительной информации о приближаемой функции f.

Добавляются дополнительные точки x0 < x1 и xn + 1 > xn, а также значения f(x0) и f(xn + 1).

Экстраполяция в приграничных узлах

Этот метод используется, когда нет никакой дополнительной информации о приближаемой функции f.

Пусть Qk(x) - интерполяционный многочлен Лагранжа степени k − 1, построенный по точкам x1, ..., xk, а Rk(x) - интерполяционный многочлен Лагранжа степени k − 1, построенный по точкам xn − k + 1, ..., xn, k ≥ 3.

$$ \begin{cases} (Pf)'(x_1) = Q'_k(x_1), & (Pf)'(x_n) = R'_k(x_n) \\ (Pf)''(x_1) = Q''_k(x_1), & (Pf)''(x_n) = R''_k(x_n) \\ \end{cases} $$

Эти значения используются в методах вместо первой и второй производной в граничных точках.
