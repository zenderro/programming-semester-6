Задача линейной интерполяции

Дано: исходная функция \(f : X → Y\), «базис» \(g_i : X → Y \qquad f, g_i ∈ F(X,Y)\), условия интерполяции \(λ_j : F(X, Y) → 𝐑\)

Найти: \(Pf = \sum\limits^n_{i=1} α_i \, g_i\), такую, что \(λ_j[Pf] = λ_j[f]\).

\(\color{red}{λ_j(f)}\), \(\color{blue}{f}\), \(\color{green}{Pf}\)

Постановка задачи линейной интерполяции

\(G(X, Y)\) — линейная оболочка \(\{g_i\}\) в \(F(X,Y)\) размерности \(n\)

\(Λ(X, Y)\) — линейная оболочка \(\{λ_j\}\) в \(F^*(X, Y)\) размерности \(m\)

Найти \(P : F(X, Y) → G(X, Y)\) т.ч. \(λ(f)=λ(Pf) | λ ∈ Λ\).

Теорема (с. 12). При линейно независимых \(g_i\) и \(λ_j\):

  1. Задача линейной интерполяции корректна \(⇔\) \(m=n\) и матрица \(A = (λ_j(g_i))\) обратима;
  2. Вектор коэффициентов \(α = (α_i) = A^{-1} (λ_j(f))\)
  3. Идемпотентность \(P\) - \(P ∘ P = P\).

\(Pf ≡ Σ_i α_i g_i\)

Обусловленность базиса

Как и в случае с решением линейных систем, необходимо учитывать вычислительную погрешность.

Число обусловленности базиса \(g_i\): \(\mathrm{cond}(g_i) = \dfrac{\max_α{K(α)}}{\min_α{K(α)}}\)

\(K(α) = \dfrac{\| \sum α_i g_i \|_G}{\| α \|_{𝐑^n}}\)

Интерполяционный многочлен Лагранжа

Работаем с функциями одной переменной на отрезке \(f : 𝐑 ⊃ [a, b] → 𝐑\)
Для точек \(a = x_1 < x_2 < … < x_n = b\) и условий \(λ_j = f(x_j)\):

\(g_i(x) ≡ l_i(x) = \prod\limits_{j \neq i} \dfrac{x - x_j}{x_i - x_j}\)

\(λ_j(l_i) = δ_{ij}\)

\(L f = \sum f(x_i) l_i\)

Число обусловленности: \(κ ⩾ C e^{n/2}\)

Число операций: \(4n^2 + O(n)\)

Наивная реализация

  1. \(Y_i = \dfrac{f(x_i)}{\prod\limits_{j \neq i} (x_i - x_j)}\qquad\) \(2n(n - 1)\) операций
  2. \(φ(x) = \prod_i (x - x_i) \qquad\) \(n + n - 1\) операций
  3. \(L f(x) = φ(x) \sum \dfrac{Y_i}{x - x_i}\qquad\) \((n - 1) + (n + 1)\) операций
    Итого - \( 2n^2 + O(n)\) операций — есть значительно более быстрый способ.

int method_init(int n, double *x, double *f, double *a);
double method_compute(double x, double a, double b, int n, double *x_array, double *a_array);
  • реализовать графический интерфейс для тестирования методов приближения функций

method_init

int method_init(int n, double *x, double *f, double *a;

Первая функция вычисляет коэффициенты приближения и сохраняет их в массив a_array. Аргументы первой функции:

  • n — количество точек
  • x — массив x длины n с точками приближения
  • f — массив значений \(f\) в точках приближения
  • a — память для хранения коэффициентов приближения

Могут быть дополнительные вектора, если алгоритму требуется дополнительная память (например, производные первого или второго порядка).

method_compute

double method_compute(double x, double a, double b, int n, double *x_array, double *a_array);

Вторая функция вычисляет значение приближения \(Pf\), заданное в массиве a_array в точке x.

  • x — аргумент функции
  • a, b — отрезок \([a, b]\)
  • n — количество точек, по которым выполнялось приближение
  • x_array — массив точек приближения
  • a_array — массив коэффициентов приближения

Тем, кто использует C++ может быть удобнее написать класс, который хранит n и a_array в полях. Тогда можно единообразно обрабатывать при рисовании исходную функцию и приближение (через базовый класс).

Графический интерфейс

Будем использовать заготовку на Qt. Заготовка доступна в GitHub по ссылке: https://github.com/MSU-Math/qt5-approximation-template

Для сборки вам понадобится установленная версия Qt5 и команды:

qmake
make

В дисплейных классах вместо qmake нужно использовать команду qmake-qt5

Установка Qt

Есть несколько вариантов:

  1. Установка пакета в Ubuntu: sudo apt-get install qt5-default
  2. Установка старой версии через офлайн-установщик: https://www.qt.io/offline-installers
  3. Установка через онлайн-установщик (нужна регистрация): https://www.qt.io/download-qt-installer

При установке провьте, что отмечен Qt Creator, он может открыть файл проекта basic_graph.pro

Qt

Проще компилировать в терминале. Вместо Makefile используется файл проекта:

HEADERS       = window.h
SOURCES       = main.cpp \
              window.cpp
QT += widgets

Сборка (в каталоге с программой):

qmake        # qmake-qt5 в дисплейных классах
             # Для отладки: qmake CONFIG+=debug
make
