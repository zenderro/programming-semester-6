# Общая схема

Пусть заданы точки $a = x_1 < x_2 < ... < x_n = b$ и значения $f(x_i)$ в этих точках.

На каждом отрезке $[x_i, x_{i+1}]$ $Pf$ - многочлен 3 степени:

$$
\begin{equation}
\begin{cases}
P_i(x_i) = f(x_i),& P_i(x_{i+1}) = f(x_{i+1}), \\
P'_i(x_i) = d_i,& P'_{i+1}(x_{i+1}) = d_{i+1} \\
\end{cases}
\end{equation}
$$

$$d_i$$ - свободные параметры, выбор которых определяется конкретным методом

# Общая схема

$$P_i(x) = a_{1,i} + a_{2,i}(x-x_i) + a_{3,i}(x-x_i )^2 + a_{4,i}(x-x_i)^2(x-x_{i+1})$$

$$
\begin{equation}
\begin{cases}
a_{1,i} = f(x_i) \\
a_{2,i} = d_i \\
a_{3,i} = \frac{f(x_i;x_{i+1}) - d_i}{x_{i+1} - x_i} \\
a_{4,i} = \frac{d_i + d_{i+1} - 2f(x_i;x_{i+1})}{(x_{i+1} - x_i)^2} \\
\end{cases}
\end{equation}
$$

$f(x_i;x_{i+1})=\frac{f(x_{i+1})-f(x_i)}{x_{i+1}-x_i}$ - разделенная разность

# Общая схема

$$P_i(x) = c_{1,i} + c_{2,i}(x-x_i) + c_{3,i}(x-x_i)^2 + c_{4,i}(x-x_i)^3$$

$$
\begin{equation}
\begin{cases}
c_{1,i} = a_{1,i} = f(x_i) \\
c_{2,i} = a_{2,i} = d_i \\
c_{3,i} = a_{3,i} - a_{4,i}(x_{i+1}-x_i) = \frac{3f(x_i;x_{i+1})-2d_i-d_{i+1}}{x_{i+1}-x_i} \\
c_{4,i} = a_{4,i} = \frac{d_i + d_{i+1} - 2f(x_i;x_{i+1})}{(x_{i+1} - x_i)^2} \\
\end{cases}
\end{equation}
$$

# Кусочная интерполяция кубическими многочленами Эрмита

$$d_i = f\ '(x_i)$$

Свойства:

1. $$||f-Pf||_{C([a,b])}\le \frac{1}{4!}\frac{1}{2^4}h^4||f^{(4)}||_{C([a,b])}$$, где 
$$h=\max_{i} (x_{i+1}-x_i)$$
2. Значения $Pf$ зависят только от значений $f$ и $f\ '$ в точках $x_i$ и $x_{i+1}$
3. $Pf$ линейно. $P(f+ g) = Pf + Pg , P (\alpha f ) =\alpha Pf$

# Кусочная интерполяция кубическими многочленами Бесселя

$$P_{(i)}(x) = f(x_{i-1}) + (x-x_{i-1})f(x_{i-1};x_i) + (x-x_{i-1})(x-x_i)f(x_{i-1};x_i;x_{i+1})$$

$$d_i = P'_{(i)}(x_i) = \frac{(x_{i+1}-x_i)f(x_{i-1};x_i) + (x_i-x_{i-1})f(x_i;x_{i+1})}{x_{i+1}-x_{i-1}}$$, где $$i=2,3,...,n-1$$

В случае равномерного распределения точек $x_i$: $d_i=\frac{f(x_{i+1})-f(x_{i-1})}{2h}$, где $$i=2,3,...,n-1$$

Недостающие значения $d_1$ и $d_n$ определяются отдельно.

# Кусочная интерполяция кубическими многочленами Бесселя

Свойства:

1. $$||f-Pf||_{C([x_2,x_{n-1}])}\le const\cdot h^3||f||_C^{(3)}([a,b])$$
2. Значения $Pf$ зависят только от значений $f$ в точках $x_{i-1}, x_i, x_{i+1}, x_{i+2}$
3. $Pf$ линейно. $P(f+ g) = Pf + Pg , P (\alpha f ) =\alpha Pf$

# Кусочная интерполяция кубическими многочленами Акимы

$$
d_i = 
\begin{cases}
\frac{w_{i+1}f(x_{i-1};x_i)+w_{i-1}f(x_i;x_{i+1})}{w_{i+1}+w_{i-1}}, & если\  w^2_{i+1}+w^2_{i-1} \ne 0 \\
\frac{(x_{i+1}-x_i)f(x_{i-1};x_i) + (x_i - x_{i-1})f(x_i;x_{i+1})}{x_{i+1}-x_{i-1}}, & если\ w_{i+1}=w_{i-1}=0
\end{cases} \\
, где\ i=3, 4, ..., n-2 \\
w_j = |f(x_j;x_{j+1})-f(x_{j-1};x_j)|
$$

Недостающие значения $d_1$, $d_2$, $d_{n-1}$ и $d_n$ определяются отдельно.

# Кусочная интерполяция кубическими многочленами Акимы

Свойства:

1. $$||f-Pf||_{C([x_3,x_{n-2}])}\le const\cdot h^2||f||_C^{(2)}([a,b])$$
2. Значения $Pf$ зависят только от значений $f$ в точках $x_{i-2}, x_{i-1}, x_i, x_{i+1}, x_{i+2}, x_{i+3}$
3. $Pf$ **не** линейно. $P(f+ g) \ne Pf + Pg$ , хотя $P (\alpha f ) =\alpha Pf$


# Кусочная интерполяция кубическими многочленами с использованием разделённых разностей

$$
d_i =
\begin{cases}
sign\ f(x_i;x_{i+1})\cdot min{{|f(x_{i-1};x_i)|, |f(x_i; x_{i+1})|}}, & если\ sign\ f(x_{i-1};x_i) = sign\ f(x_i;x_{i+1}) \\
0 & иначе
\end{cases} \\, где\ i=2, 3, ..., n-1 \\
$$

Недостающие значения $d_1$ и $d_n$ определяются отдельно.

# Кусочная интерполяция кубическими многочленами с использованием разделённых разностей

Свойства:

1. $$||f-Pf||_{C([x_2,x_{n-1}])}\le const\cdot h^2||f||_C^{(2)}([a,b])$$
2. Значения $Pf$ зависят только от значений $f$ в точках $x_{i-1}, x_i, x_{i+1}, x_{i+2}$
3. $Pf$ **не** линейно. $P(f+ g) \ne Pf + Pg$, хотя $P (\alpha f ) =\alpha Pf$

# Определение недостающих граничных условий

1. По известным значениям первой производной функции в граничных узлах
2. По известным значениям второй производной функции в граничных узлах
3. "Естественные граничные условия"
4. Условие "отсутствия узла" в приграничных узлах
5. Дополнительный узел в приграничных узлах
6. Экстраполяция в приграничных узлах

# По первой производной

$$d_1 = f\ '(x_1), d_n = f\ '(x_n)$$

Для метода Акимы дополнительно: $$d_2 = f\ '(x_2), d_{n-1} = f\ '(x_{n-1})$$

# По второй производной

$$\begin{cases}
2d_1 + d_2 = 3f(x_1;x_2) - \frac{1}{2}f''(x_1)(x_2-x_1) \\
d_{n-1} + 2d_n = 3f(x_{n-1};x_n) + \frac{1}{2}f''(x_n)(x_n-x_{n-1})\\
\end{cases}$$

В методе Акимы $d_2$ и $d_{n-1}$ определяются по первой производной. В остальных методах эти параметры известны.

# Естественные граничные условия

$$(Pf)''(x_1)= 0, (Pf)''(x_n) = 0$$

При $f\ ''(x_1)=0$ и $f\ ''(x_n) = 0$ получаем
$$
\begin{cases}
2d_1+d_2 = 3f(x_1;x_2) \\
d_{n-1}+2d_n = 3f(x_{n-1};x_n)\\
\end{cases}
$$

В остальных случаях повышенная погрешность в граничных узлах.

# Отсутствие узла в приграничных узлах

Считаем, что $$ P_1 \equiv P_2, P_{n-2} \equiv P_{n-1}$$.

В этом случае $P_1$ интерполирует $f$ на отрезке $[x_1,x_3]$ по точкам $x_1, x_2, x_3$. $P_{n-1}$ - на отрезке $[x_{n-2},x_n]$ по точкам $x_{n-2}, x_{n-1}, x_n$.

Тогда $P\ '_1(x_3) = d_3, P\ '_{n-1}(x_{n-2})=d_{n-2}$

$P_1 \equiv P_2$ и $P_{n-2}\equiv P_{n-1}$ строятся как интерполяционные многочлены 3й степени.

# Экстраполяция в приграничных узлах

Пусть $Q_k(x)$ - интерполяционный многочлен Лагранжа степени $k-1$, построенный по точкам $x_1, ..., x_k$, а $R_k(x)$ - интерполяционный многочлен Лагранжа степени $k-1$, построенный по точкам $x_{n-k+1}, ..., x_n, k\ge 3$.

$$
\begin{cases}
(Pf)'(x_1) = Q'_k(x_1), & (Pf)'(x_n) = R'_k(x_n) \\
(Pf)''(x_1) = Q''_k(x_1), & (Pf)''(x_n) = R''_k(x_n) \\
\end{cases}
$$

Эти значения используются в методах вместо первой и второй производной в граничных точках.
